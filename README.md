# AeroMed Relay

Clickable prototype, recorded demonstration and supporting documents for **RECM**
(referral and evidence coordination for aeromedical assessments, Kenya KCAA pathway).
Applied Health Informatics individual assignment, Shariffa Abdulhamid Garwan.

**Simulated data only.** Every name, licence number and file is made up. Not for clinical use.
RECM does not decide fitness to fly and does not replace the authorised KCAA submission channel.

- `AeroMed-Relay-Demo.html`: the interactive demo (one file, works offline)
- `AeroMed-Relay-Demo-Video.mp4`: recorded walk-through (3 min 55 s, computer-generated voice)
- `documents/`: user guide and demo check report (PDF)
- `index.html`: landing page
